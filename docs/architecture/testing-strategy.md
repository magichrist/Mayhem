# Testing Strategy

Tgondi is a tool whose job is breaking things reliably — its own reliability claims must be tested
with the same rigor it applies to others. Record: [ADR-0002](../adr/0002-python-single-package-layered-monorepo.md)
(tooling), [ADR-0005](../adr/0005-recovery-model-lease-journal-janitor.md) (recovery invariants).

---

## 1. Pyramid

| Tier | What | Tools | Speed gate |
|---|---|---|---|
| Unit | domain validators, planner math, DSL compiler, config layering, safety gates | pytest + hypothesis | < 10s, no IO |
| Contract | every tool adapter against **fake binaries**; protocol framing; migration runner | pytest | < 60s |
| Integration | controller+agent over local stdio transport; real SQLite; real Docker (skipped if unavailable); compose fixture stack | pytest + testcontainers-style fixtures | < 10min |
| E2E chaos-of-the-chaos | kill things at random points; assert recovery invariants | pytest, seeded randomness | nightly |

## 2. Fake tool binaries

`tests/fixtures/bin/` ships scriptable fakes (`tc`, `iptables`, `stress-ng`, `docker`, …) that
record argv to a sidecar file and simulate success/failure/timeout per a scenario env var.
Contract tests run adapters against these — deterministic, root-free, CI-cheap. A small matrix of
integration tests additionally runs *real* tools inside the Docker fixture stack.

## 3. Fixture stacks

Versioned compose files under `tests/fixtures/composes/`:
`web_db` (nginx+fastapi+postgres+redis), `multihost_sim` (network namespaces simulating hosts),
`podman_parity` (same as web_db for podman). Integration tests parameterize over available
runtimes; missing runtime ⇒ skip with reason, never fail.

## 4. Determinism tests

Property-based: same seed + same topology/config snapshot ⇒ byte-identical plan and identical
Maniac selection sequence ([ADR-0009](../adr/0009-maniac-deterministic-weighted-stochastic-planner.md)).
Mutation: changing any scoring input must change recorded scores but never violate safety gates.

## 5. Migration & storage tests

Every migration runs forward on an empty DB and on snapshots of all prior schema versions;
round-trip tests assert domain models serialize/deserialize losslessly through rows.

## 6. Chaos-of-the-chaos (the tier that earns trust)

Seeded harness kills components at randomized points:

| Scenario | Invariant asserted |
|---|---|
| SIGKILL controller mid-injection | after watchdog TTL: fault compensated locally; janitor converges DB |
| SIGKILL agent mid-recovery | janitor path completes compensation from undo_json |
| Channel drop (kill SSH master) | lease `orphaned` → reconciled; run marked `aborted(recovered)` |
| Crash between undo-write and inject | pending lease deleted; nothing leaked |
| ABORT during multi-fault parallel step | all leases released reverse-order; verify probes pass |

Convergence assertion helper: poll until zero non-terminal leases AND all verify probes pass,
bounded timeout, else fail loudly. These tests run nightly and pre-release.

## 7. Fault-catalog coverage matrix

Generated by `tgondi dev coverage-matrix > docs/fault-catalog/matrix.md`: rows = faults, columns =
target context × backend × privilege level. A cell counts as covered **only** when an automated
test injects the fault via that backend and verifies recovery ([fault-taxonomy](fault-taxonomy.md)).
CI fails when a claimed-MVP fault lacks any green cell — coverage claims are test-gated, not
asserted.

## 8. Lint & type discipline

`ruff` (lint+format), `mypy --strict` on `src/`, pyright parity optional. Pre-commit hooks run both
plus a secret scan. CI = GitHub Actions matrix (3.12, 3.13 × ubuntu) + macOS job for host-path
parity.

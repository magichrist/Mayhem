# Kubernetes runtime family status

The next-20 Kubernetes families are implemented through the existing workload, service, config, storage, node, and HPA executor lanes. Their current definitions and status are listed in [`reference/fault-catalog.md`](reference/fault-catalog.md).

The older `k8s-new.md` milestone is retained as a source reference for the workload snapshot lane. It is not a separate authority: current catalog entries, runtime unions, and unit tests control behavior.
